## Detail Evaluasi & Usulan Perbaikan (Before → Proposed)

### 1. `src/app/extension/ExtensionContent.tsx` — Eyebrow Duplication
- **Before**:
  Line 120: `<span className="... text-site-accent">{t("extension.heroTitle")}</span>` (teks: *"The Bug Reporting Extension Built for Developers & QA"*)  
  Line 133: `<h2 className="...">{t("extension.heroTitle")}</h2>` (teks yang sama persis diulang di bawahnya)
- **Proposed**:
  Ganti eyebrow pada baris 120 menjadi label kategori fungsional yang ringkas, misal `t("extension.overview")` (*"Chrome Extension"* / *"Ekstensi Chrome"*), sehingga judul `<h2>` tetap menjadi fokus utama.

### 2. `src/app/extension/ExtensionContent.tsx` — Hardcoded English Strings
- **Before**:
  - Line 158: `<span>Capture Modes</span>`
  - Lines 162-164: `<span>Monitor</span>`, `<span>Window</span>`, `<span>Tab</span>`
  - Line 227: `<span>Workflow</span>`
  - Line 263: `<span>Compatibility</span>`
  - Line 316: `<span>FAQ</span>`
- **Proposed**:
  Daftarkan kunci baru pada `src/lib/i18n/marketing.ts` (`extension.captureModes`, `extension.modeMonitor`, `extension.modeWindow`, `extension.modeTab`, `extension.sectionWorkflow`, `extension.sectionCompatibility`, `extension.sectionFaq`) dalam bahasa Inggris dan Indonesia.

### 3. `src/lib/i18n/marketing.ts` — "In 3 Simple Steps"
- **Before**:
  EN: `"How It Works in 3 Simple Steps"`  
  ID: `"Cara Kerja dalam 3 Langkah Mudah"`
- **Proposed**:
  EN: `"How BugSnap works"`  
  ID: `"Cara kerja BugSnap"`

### 4. `src/lib/i18n/marketing.ts` — Redundant Step Numbering
- **Before**:
  EN: `"1. Install in One Click"`, `"2. Capture Any Bug"`, `"3. Share With Your Team"`  
  ID: `"1. Pasang dalam Satu Klik"`, `"2. Tangkap Bug Apa Saja"`, `"3. Bagikan ke Tim Anda"`
- **Proposed**:
  EN: `"Install the extension"`, `"Capture any bug"`, `"Share with your team"`  
  ID: `"Pasang ekstensi"`, `"Tangkap bug"`, `"Bagikan ke tim"`

### 5. `src/lib/i18n/marketing.ts` — Negative Parallelism & Intrusive Tone
- **Before**:
  EN: `"The extension silently intercepts console exceptions and HTTP 4xx/5xx network errors from the active tab. No manual DevTools copy-pasting."`  
  ID: `"Ekstensi menangkap exception console dan error jaringan HTTP 4xx/5xx secara diam-diam dari tab aktif tanpa perlu buka DevTools manual."`
- **Proposed**:
  EN: `"The extension captures console exceptions and HTTP 4xx/5xx network errors from the active tab in the background, eliminating manual DevTools copy-pasting."`  
  ID: `"Ekstensi merekam exception console dan kegagalan HTTP 4xx/5xx secara otomatis di latar belakang, tanpa perlu menyalin log DevTools secara manual."`

### 6. `src/lib/i18n/marketing.ts` — Significance Inflation / Enterprise Jargon

  ID: `"100% Kepemilikan Data"`
- **Proposed**:
  EN: `"Stored in your Google Drive"`  
  ID: `"Tersimpan di Google Drive Anda"`

### 7. `src/lib/i18n/marketing.ts` — AI Filler Word "Modern"
- **Before**:
  ID: `"Ekstensi Pelaporan Bug untuk Developer & QA Modern"`
- **Proposed**:
  ID: `"Ekstensi Pelaporan Bug untuk Developer & Tim QA"`

### 8. `src/lib/i18n/marketing.ts` — Canned Template CTA
