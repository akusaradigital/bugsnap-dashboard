# AGENTS.md - BugSnap Dashboard (non-Claude engines)

> `CLAUDE.md` (same directory) is canonical and holds every rule for this repo - read it. This file carries no separate rule text to avoid drifting out of sync. Cross-repo rules: `../CLAUDE.md`. Brand/logo rules: `../BRAND.md`.
>
> **Local Commit Rule (MANDATORY for Multi-Agent Safety):** Commit locally often! Whenever a task/fix passes verification, make a local `git commit`. NEVER leave completed work uncommitted in the working tree. Local commits do not push to remote.
>
> **Version & Changelog rule:** Version bumps and changelog updates are done ONLY when preparing a production release (not on every code change). Full procedure in `CLAUDE.md` §2.
>
> **No "- Free" / "- Gratis" rule:** Never use "- Free" or "- Gratis" in CTAs, buttons, or page titles (use clean "Add to Chrome", "Add to Firefox", "Tambah ke Chrome", "Tambah ke Firefox").
